# JavaScript Projects

These are the projects and challenges I made during my JavaScript course. Each one covers a different part of JavaScript, from the basics up to things like AJAX, jQuery and React.

## Projects

- Basic JavaScript projects (expressions, events, functions, math operators)
- Dictionaries and comparisons
- Ternary operators and constructors
- Scope and time functions
- String methods
- Loops and arrays
- Countdown and slideshow
- To-Do List
- Calculator
- Tic-Tac-Toe
- Pizza Menu
- AJAX, jQuery and React
- Portfolio website

## Basic JavaScript Projects

The early projects cover the fundamentals. I worked through expressions and alerts, events, functions, math operators, dictionaries, comparisons and type coercion, ternary operators and constructors, scope, string methods, loops and arrays. Each one is a small page that shows the concept working in the browser.

## To-Do List

A simple to-do list app. You can type a task, add it to the list, and remove it with the x button next to each item. The tasks are saved in the browser using localStorage, so they are still there when you come back.

## Calculator

A basic 4 function calculator. You can add, subtract, multiply and divide, and it is styled to look like a simple calculator.

## Tic-Tac-Toe

The classic tic-tac-toe game. You play against the computer, it places its move after you, and when someone wins a line is drawn across the winning squares with a sound.

## Pizza Menu

A menu used to order pizza. You pick a size, meats and veggies, and it works out the total price for the order and shows a receipt.

## AJAX, jQuery and React

Smaller projects where I tried out AJAX to load content, jQuery to change the page, and React to build components (including a counter, a like button and JSX).

## Portfolio

A personal portfolio page that pulls together a lot of what I learned, with a nav bar, a projects slideshow, an about section and a contact form.
